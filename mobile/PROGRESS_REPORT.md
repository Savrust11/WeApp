# We育（ウィーク）モバイルプロジェクト 開発進捗レポート

**作成日：** 2026年4月6日
**プロジェクト名：** We育 — パートナーと一緒に育児を楽しもう
**プラットフォーム：** iOS / Android / Web

---

## 1. プロジェクト概要

We育は、パートナーと一緒に育児を楽しく・効率的に行うための子育て支援アプリです。
日々の育児記録、健康管理、睡眠トレーニング、食品管理など、幅広い機能を備えています。

**技術スタック：**

| 項目 | 技術 |
|------|------|
| フレームワーク | Expo SDK 55 / React Native 0.83 |
| 言語 | TypeScript |
| 状態管理 | Zustand |
| データ取得 | TanStack React Query |
| フォーム | React Hook Form + Zod |
| 多言語対応 | i18next |
| バックエンド | Express 5 + PostgreSQL (Neon) |
| 認証 | LINE / Google / Apple |
| ORM | Drizzle ORM |

## 4. 認証システム

3つのソーシャルログインに対応しています。

### LINE ログイン ✅ 実装済み
- サーバーサイドリダイレクトフロー
- Web / ネイティブ両対応
- ディープリンク（`weyu://auth/callback`）でアプリに戻る

### Google ログイン ✅ 実装済み
- **Web版：** ブラウザリダイレクトフロー（COOP問題を回避）
- **ネイティブ版：** サーバーサイドリダイレクトフロー（LINEと同様のパターン）
- Google Cloud Console でのクライアントID設定が必要

### Apple ログイン ✅ 実装済み
- iOS専用のネイティブ認証
- identityToken による検証

### ゲストログイン ✅ 実装済み
- アカウント不要でオンボーディングへ進む

## 6. 開発環境・テスト構成

### ローカル開発
- **Express（バックエンド）：** ポート 5000
- **Expo（モバイルWeb）：** ポート 8082
- **開発プロキシ：** ポート 8081（API→Express、その他→Expo）

### 外部アクセス（ngrok）
- ngrok → ポート 8081（開発プロキシ）
- プロキシが `/api` リクエストをExpress に、その他をExpoに振り分け
- Google OAuth や LINE ログインのテストに利用

### Android テスト
- EAS Build によるクラウドビルド（開発ビルド）
- APK をデバイスにインストールして接続
- `EXPO_PUBLIC_API_URL` を ngrok URL に設定

## 7. 対応済みの技術的課題

### Google OAuth の COOP 問題 ✅ 解決済み
- Webブラウザでのポップアップ方式がGoogle の Cross-Origin-Opener-Policy により動作しない問題
- **解決策：** Web版はページリダイレクト方式、ネイティブ版はサーバーサイドリダイレクト方式に変更

### ngrok 経由でのAPI接続 ✅ 解決済み
- Expo 開発サーバー（8081）とExpress API（5000）が別ポートで動作する問題
- **解決策：** 開発プロキシサーバーを作成し、単一の ngrok トンネルで両方にアクセス可能に

### React Native Web の互換性 ✅ 解決済み
- `Alert.alert()` がWebで動作しない問題
- **解決策：** Web では `window.confirm()` / `window.alert()` にフォールバック

### 記録機能の400エラー ✅ 解決済み
- `POST /api/logs` で `userId` が欠落していた問題
- **解決策：** 認証ストアからユーザーIDを取得して送信するように修正
